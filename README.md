# Strategic Lifecycle Analysis of Grand Theft Auto VI

## Objective
Analyze Rockstar Games’ development lifecycle to understand scaling trends, investment strategy, and market expectations for GTA VI.

## Tools Used
- Python
- Pandas
- Matplotlib

## Dataset
- rockstar_lifecycle_data.csv – raw, manually collected dataset
- rockstar_lifecycle_cleaned.csv – Python-processed dataset used for analysis

## Key Insights
- Rockstar’s development cycles have increased significantly over time, reflecting rising project complexity.
- Higher development investment correlates with exponential revenue growth, indicating a high-risk, high-return strategy.
- GTA VI aligns with Rockstar’s long-term strategic investment approach rather than being an anomaly.

## Assumptions
- Budget and revenue figures are based on publicly available industry estimates.
- GTA VI figures are projections derived from historical benchmarks.

## Deliverables
- Cleaned dataset
- Lifecycle analysis visualization
- Cost vs revenue scaling visualization
